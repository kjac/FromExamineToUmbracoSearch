# Demo site for Umbraco Search

This repo contains the sample site for my [blog post](https://kjac.dev/posts/from-examine-to-umbraco-search/) about migrating site search from Examine to Umbraco Search.

Check the blog post for details 🙂

Note that the V19 site in this repo is built with a beta version of Umbraco 19, which is not available on NuGet.
